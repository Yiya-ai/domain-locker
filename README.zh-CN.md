# Domain Locker 域名台账

基于 Domain Locker 0.3.7（上游提交 `c0e8ad8`），保留原项目的 MIT 许可证。新增台账按 MiPanel 的字段和 CSV 格式独立实现。

## 在 Windows 使用

- **完整版**。双击 `启动域名台账.cmd`，首次启动按提示输入两次至少 12 位的登录密码，然后在浏览器打开 http://127.0.0.1:43973/domains/ledger 登录。窗口需保持打开。启动器默认仅监听本机，币种为 CNY。旧账本登记了外币时，启动前请将 `DL_PORTFOLIO_CURRENCY` 设为原币种。
- **离线版**。在浏览器打开 `dist/portable/domain-ledger.html`，首次设置独立密码。刷新、关闭或点击“锁定”后需要重新解锁。原版 IndexedDB 记录会在首次设置密码时原子迁移至 AES-GCM 加密存储。请保管好密码，换电脑、换浏览器或移动 HTML 前先导出备份。
- **从源码构建**。使用项目 `.nvmrc` 指定的 Node 版本或兼容的 Node 24，在项目目录运行 `npm ci`、`npm run build`、`npm run build:portable`。私有发行归档可使用 `npm pack`。

## 数据、口令和备份

完整版的默认账本位于 `data/domain-locker.db`。首次启动新版前关闭所有旧进程，备份账本及仍存在的同名 WAL 和 SHM 文件，并保护好这份旧明文备份。新版成功打开旧账本时，SQLite 会在事务内加密旧数据。Windows 启动器生成独立数据库密钥，登录凭据和数据库密钥分别用当前 Windows 用户的 DPAPI 保护，位于 `%LOCALAPPDATA%/DomainLocker/`。登录密码与数据库密钥用途不同，仅复制数据库文件或 DPAPI 文件到另一台电脑不足以恢复。

跨机完整备份请在首次启动前自行设置高熵的 `DL_DB_KEY` 并存入密码管理器，同时备份已关闭的数据库；已有加密库必须沿用原密钥。启动器自动生成密钥的现有用户可在同一 Windows 用户的 PowerShell 会话中用 `Get-Content -Raw` 读取 `database.dpapi` 并通过 `ConvertTo-SecureString` 解封，交由可信密码管理器保存。不要把密钥写入项目目录。CSV 用于跨版本交换，含明文商业信息，导出默认防止电子表格解释公式；需要原样保留文本时，可在导出窗口取消该选项并仅导入可信台账。

## 自托管与外部查询

Docker Compose 默认从本地代码构建并绑定回环地址。SQLite 部署需通过运行环境设置 `DL_AUTH_PASSWORD` 和至少 16 位的独立 `DL_DB_KEY`。使用 PostgreSQL 时设置登录密码和数据库口令，数据库卷的静态加密与备份加密由 PostgreSQL 主机提供。公网访问应经启用 HTTPS 的反向代理，私人页面和接口禁止共享缓存。Helm 安装需指定自行构建的已加固镜像和 Kubernetes Secret。

完整版默认只做本地记账。管理员设置 `DL_ENABLE_EXTERNAL_QUERIES=true` 并重启后，域名查询、状态查询和外部监控才会启用。此时 DNS、登记信息提供方及被监控网站可获知查询；IP 归属服务还需配置独立的 `DL_IP_API_KEY`。浏览器使用本地图标。若配置支持邮箱，使用 `DL_SUPPORT_EMAIL` 指定收件人。离线版始终使用浏览器本地账本。

## 日常操作

从 Domains 或 Domain Valuation 打开 Domain ledger。选择“添加域名”手工记录域名、注册商、注册与到期日期、注册价、年续费、意向售价、实际售价和备注。编辑使用同一表单。完整版可从台账跳转到原域名详情，查看 DNS、监控、标签和估值，也可从详情直接编辑台账。

首页按登记的域名统计注册总投入、意向售价总额和实际成交收入。空金额表示未填写，零表示已登记为零。注册总投入仅统计注册价。到期日当天显示剩余 0 天，列入 30 天内到期。搜索支持域名、注册商和备注。

## MiPanel CSV

导入支持列顺序调整、UTF-8 BOM、中文、双引号、逗号及多行备注。预览显示记录数和重复项，确认后才写入。已有域名和文件内重复域名会被跳过，格式错误会指出记录位置。MiPanel 金额使用人民币，外币账本导入导出时需确认换算汇率。

自托管台账使用原来的域名、注册商和费用表，并新增两个可空售价字段。首次运行会执行数据库迁移。新增台账入口适用于自托管 SQLite / PostgreSQL；原上游托管 Supabase 服务独立运行。
